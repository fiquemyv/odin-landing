# Odin Landing

A landing page project built as part of [The Odin Project](https://www.theodinproject.com/) Foundations course. It showcases HTML, CSS, and Flexbox fundamentals by building a complete single-page website from scratch.

View the live project at: <https://fiquemyv.github.io/odin-landing/>

## Features

- A hero section with a headline and call-to-action button
- A navigation header with links
- Content sections laid out with Flexbox
- A sign-up call-to-action and footer

## HTML Concepts Practiced

- **Boilerplate** – `<!DOCTYPE html>`, `<html>`, `<head>`, and `<body>`
- **Headings** – `<h1>` through `<h3>` for page and section titles
- **Paragraphs** – `<p>` for descriptions
- **Links** – `<a>` for navigation and call-to-action buttons
- **Images** – `<img>` with `src` and `alt` attributes
- **Buttons** – `<button>` for interactive actions
- **Lists** – unordered lists `<ul>` for navigation and footer links
- **Semantic layout** – `<header>`, `<section>`, and `<footer>` for page structure

## CSS Concepts Practiced

- **Flexbox** – `display: flex` to align and distribute items
- **Box model** – padding, margin, and border for spacing
- **Colors and backgrounds** – hero, section, and footer styling
- **Typography** – font-family, font-size, and font-weight
- **Alignment and justification** – `justify-content` and `align-items`
- **Hover effects** – styling interactive elements

## Usage

Open `index.html` in a browser to view the landing page.
